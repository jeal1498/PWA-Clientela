# Clientela

Tus clientes, en orden. PWA para conductores (Uber, DiDi, taxi, choferes independientes): agenda, cotizaciones, cobros y WhatsApp de sus clientes privados.

- Publicada en https://jeal1498.github.io/PWA-Clientela/
- Sin build ni dependencias: HTML + CSS + JS (ES modules). Se sirve tal cual.
- Datos en `localStorage` (clave `cartera`).
- Plan y avance: [`PLAN.md`](PLAN.md). Marca: [`marca/`](marca/README.md).

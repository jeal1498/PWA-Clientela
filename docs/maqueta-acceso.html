Cómo funciona por dentro

  1. Entrar: botón de Google dentro de la app (la misma lógica de Checa). Se necesita agregar https://jeal1498.github.io como origen autorizado del cliente web en Google Cloud.
  2. Sincronizar: clientes, viajes y ajustes viajan a Supabase unos segundos después de cada cambio. Lo borrado se marca, no se pierde.
  3. Dos teléfonos: gana el cambio más reciente de cada cliente o viaje. Nada se sobrescribe completo.
  4. Privacidad: cada fila lleva tu usuario y solo tú la lees. La clave pública va en la app; la seguridad la pone la base de datos.
